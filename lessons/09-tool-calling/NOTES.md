# Урок 9. Tool calling: один инструмент (конспект)

Цель: дать модели доступ к базе отзывов через функцию поиска.

- **Без инструмента модель выдумывает**: на вопрос про баги ответила общими словами, потому что базы не видит.
- **Функцию запускает мой код, а не модель.** Модель только отвечает «вызови `searchReviews` с `category: "bug"`», аргумент выбирает сама.
- **Шагов два**: 1) модель просит вызвать инструмент, 2) мой код выполняет `filter`, отдаёт результат модели, и она пишет ответ. Чтобы второй шаг случился, нужен `stopWhen: isStepCount(3)`, по умолчанию шаг один.
- **Модель сама решает, нужен ли инструмент**: на «Привет! Как дела?» не вызвала.
- **`description` — это промпт.** Модель не видит код `execute`, только имя, описание и `inputSchema`. С описанием «Поиск ошибок по полю категория» вопрос «о чём нас спрашивают?» не сработал: модель попросила назвать категорию. Когда расписал в описании, что значит каждая категория, вызвала `searchReviews("question")`.
- **Три места для промпта**: `instructions`, `description` инструмента, `.describe()` у полей схемы.
