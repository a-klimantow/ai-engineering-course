# Урок 9. Tool calling: один инструмент

Код урока: `projects/feedback-inbox/ask.ts` и `data.ts`.

## Разминка

1. Почему схема лежит в отдельном `schema.ts`?
2. Зачем отзыв заворачивать в `<review>...</review>`?

## Зачем

Модель знает только то, что было в её обучении и в твоём промпте. Твоей базы отзывов она не видит. Tool calling это исправляет: ты описываешь модели функцию, и она сама решает, когда её вызвать и с какими аргументами. Так работают все «AI-ассистенты» в продуктах: поиск по заказам, создание задачи, запрос в CRM.

Важно: модель функцию не запускает. Она только возвращает «вызови `searchReviews` с `category: "bug"`». Запускает твой код, а результат уходит модели вторым запросом.

## Практика

### Шаг 1. Посмотри, как модель отвечает без доступа к базе

```bash
npm run inbox:ask
```

Ожидаемый вывод примерно такой:

```
Шагов: 1
Пользователи сообщают различные баги, от ошибок в функционале до проблем с безопасностью.
```

Ответ общий и выдуманный: настоящих отзывов из `data.ts` модель не видела.

### Шаг 2. Дай модели инструмент

Открой `projects/feedback-inbox/ask.ts`.

1. Замени строку `// TODO (урок 9): ...` на каркас и заполни три места с `???`:

   ```ts
   const searchReviews = tool({
     description: ???,   // одна фраза по-русски: что делает инструмент. Модель читает её, чтобы решить, вызывать ли
     inputSchema: z.object({ category: ??? }),   // те же пять категорий, что в схеме Review
     execute: async ({ category }) => {
       console.log(`🔧 модель вызвала searchReviews("${category}")`)
       return ???   // отзывы из STORED_REVIEWS с этой категорией
     },
   })
   ```

2. В вызов `generateText` добавь две строки после `prompt`:

   ```ts
   tools: { searchReviews },
   stopWhen: isStepCount(3),
   ```

3. Запусти `npm run inbox:ask`.

Ожидаемый вывод:

```
🔧 модель вызвала searchReviews("bug")
Шагов: 2
Вот список багов: ... (настоящие отзывы из data.ts)
```

### Шаг 3. Проверь, что модель решает сама

1. Замени `prompt` на `"Привет! Как дела?"` и запусти. Вызвала ли модель инструмент?
2. Замени `prompt` на `"О чём нас спрашивают пользователи?"` и запусти. С каким аргументом вызван инструмент?
3. Верни исходный вопрос про баги и сравни ответ модели с `data.ts`: всё ли она пересказала верно?
