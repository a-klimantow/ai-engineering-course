# Урок 3. Промптинг (конспект)

Задача: классифицировать отзывы, чтобы ответ модели можно было использовать в коде.

- **Наивный промпт** даёт длинный текст, выдуманные категории и выполняет чужие команды (инъекция).
- **System-промпт**: роль, закрытый список категорий, формат «ровно одно слово».
- **Признаки категорий**: описывай, *по чему* узнать категорию («есть «?», «можно ли»»), а не только смысл.
- **Правило для спорных случаев**: «похвала + проблема → bug».
- **Запасная категория `other`**: иначе модель угадывает наугад, когда ничего не подходит.
- **Разделители `<review>`**: данные пользователя отдельно от инструкций. Защищает частично, не полностью.
- **Few-shot**: пары user/assistant с примерами. Модель повторяет образец лучше, чем следует описанию.
- **temperature: 0** для классификации: нужна предсказуемость.
- **Осторожно с подгонкой**: примеры, подобранные под тестовые данные, могут хуже работать на новых. Проверять на отдельном наборе (evals, модуль 6).
