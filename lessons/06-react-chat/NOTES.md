# Урок 6. Чат на React с useChat (конспект)

Цель: переписать страницу чата на React и отдать ручную работу хуку `useChat`.

- **Схема**: браузер (React) → Vite :5173 → `server.ts` :3002 → Ollama. Запросы `/api/...` Vite перенаправляет на сервер (`proxy` в `vite.config.ts`). Два терминала: `lesson6:server` и `lesson6:web`.
- **`useChat()`** заменяет всё ручное из урока 4: хранит историю (`messages`), отправляет (`sendMessage({ text })`), читает стрим, даёт `stop` и `status`.
- **`status`**: `submitted` (ждём первый кусочек), `streaming` (печатается), `ready`, `error`. По нему показываем «Думаю...» и кнопку «Стоп».
- **`parts`**: сообщение — это список частей (текст, файлы, вызовы инструментов), а не одна строка.
- **Сервер** принимает сообщения в формате UI (`convertToModelMessages`) и отдаёт поток событий для useChat (`toUIMessageStream` + `pipeUIMessageStreamToResponse`), а не чистый текст.
- **System-промпт на сервере** (`instructions`): пользователь не может его увидеть или подменить через DevTools.
- **AI SDK — это не модели**, а библиотека для запросов к ним. Модель меняется одной строкой `model`: Ollama локально и бесплатно, OpenAI/Claude платно за токены.
- **Ловушка**: кнопка внутри `<form>` без `type="button"` отправляет форму.
