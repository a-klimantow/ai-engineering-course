# Урок 4. Чат в браузере (конспект)

Цель: чат на веб-странице, где ответ появляется по кусочкам.

- **Схема**: браузер → наш сервер (`server.ts`) → Ollama. Браузер не ходит в модель напрямую: в реальном проекте API-ключ хранится только на сервере.
- **Сервер** читает стрим Ollama (JSON-строки, как в `chat.ts`) и отдаёт браузеру чистый текст через `res.write(...)`.
- **Браузер** читает ответ через `res.body.getReader()` и дописывает каждый кусочек в пузырь сообщения.
- **История** хранится в браузере (`history`) и целиком уходит на сервер при каждом сообщении.
- **Кнопка «Стоп»**: `AbortController` + `signal` в `fetch`, а `try/catch` вокруг цикла чтения ловит отмену.
- **Ограничение**: «Стоп» отменяет только чтение в браузере, сервер может продолжать генерацию. С платной моделью это лишние деньги. Вернуться в модуле 6.
