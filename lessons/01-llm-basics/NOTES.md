# Урок 1. Как работают LLM (конспект)

- **Генерация**: модель предсказывает следующий токен, повторяя это шаг за шагом, поэтому возможен стриминг.
- **Токены**: куски слов. Русский текст «дороже» английского (зависит от токенизатора модели).
- **Контекстное окно**: у модели нет памяти между запросами, историю каждый раз пересылает приложение.
- **Стоимость** растёт с длиной диалога: вся история заново уходит во входные токены.
- **Температура**: низкая для извлечения данных, высокая для креатива.
- **Галлюцинации**: модель генерирует правдоподобное, а не проверенное.
- **Безопасность**: API-ключ только на сервере (+ авторизация, rate limit, лимит расходов).
