| 14 | Ошибки и повторы | интерфейс не ломается, когда модель ошиблась | ⬜ |

| 16 | Безопасность | защита от инъекций в отзывах | ⬜ |
| 17 | Evals | набор тестов на качество разметки | ⬜ |

## Формат урока

Один урок — одна идея, 20–30 минут.

1. **Разминка** (2 минуты): два вопроса по прошлому уроку.
2. **Зачем**: где эта фича нужна в реальном продукте.
3. **Практика**: не больше трёх шагов. Основной код готовый, одно небольшое место пишу сам.
4. **Конспект**: три строки в `NOTES.md` своими словами.
