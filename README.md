# 🤖 AI Engineering: учебный репозиторий

Изучаю AI Engineering с фокусом на AI-фичи во фронтенде (TypeScript).
Локальные модели: [Ollama](https://ollama.com).

## Прогресс

| # | Модуль | Статус |
|---|---|---|
| 1 | Как работают LLM (токены, контекст, температура) | ✅ |
| 2 | Промптинг и первый вызов API | ✅ |
| 3 | Чат в UI: стриминг, Vercel AI SDK | ⏳ |
| 4 | Структурированный вывод (Zod) и tool calling | ⬜ |
| 5 | RAG: поиск по своим данным | ⬜ |
| 6 | Прод: ошибки, стоимость, безопасность, evals | ⬜ |

## Структура

- `lessons/` — упражнения и конспекты по урокам
- `projects/` — итоговые проекты модулей

## Запуск

npm install
